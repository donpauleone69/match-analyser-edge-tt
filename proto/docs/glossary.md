# Glossary

Words used in the proto, the brief and reviews. Screen areas are in [ui-zones.md](./ui-zones.md).

## Match structure

| Term | Meaning |
|------|---------|
| Match, Set, Rally, Shot | A match has sets, a set has rallies, a rally has shots. A shot is one contact. |
| You, Them | The two sides. Screens show the player names. |
| Contact | A tap on the video at the moment a player hits the ball. |
| Set mark | The start and end of one set on the match videos. One mark per set. A set may run onto the next video. |
| Complete, Part filmed | Whether the whole set is on video. |
| Gap | Video between two rallies. A gap of 9 seconds or more takes a warning tint. A gap under a second is a stop, not a gap. |
| Serve order break | A rally served by the wrong side for the score. The first one is flagged on its pill. |

## Screens and controls

| Term | Meaning |
|------|---------|
| Tag page | A match's videos and sets in one place, under one preview player. Each set has Tag, Continue or Open. |
| Set Tagger | The screen that tags one set, a rally at a time. |
| Edit Set | Steps through a set's rallies to edit or delete, and through its gaps (Gaps mode) to insert a missed rally. |
| Edit Rally | A 4x2 pad that fixes one saved rally, opening on shot 1. |
| Corner pad | The Shot Input layout: answers in the corners, BH on the left, FH on the right. |
| Not a shot | Removes a contact that was not a shot, such as a toss. |
| Save set | Ends a won set and returns to the Tag page. |

## Tagging questions

| Term | Meaning |
|------|---------|
| Best + FA | The tagging flow. FA is first attack. One question per screen, in contact order. |
| Serve | Where the serve lands, as a quadrant. |
| Shot | From shot 2 on, the wing (BH or FH) and Attack or Control. |
| Who attacked first? | You, Them or Nobody. |
| End | How the last shot ended: Winner, Net, Long or Wide. |
| Point to | Who won. Asked only when the winner cannot be worked out. |
| Parts | A rally's phases: Opening, Attack, Rally, End. Derived, never asked. |
| Derived | Anything worked out from contacts and answers: hitter, winner, score, server, parts, stats, reels. |

## Product

| Term | Meaning |
|------|---------|
| Insights | Stats for one match or all matches, each backed by reels. Not built yet. |
| Reel | Short video of the rallies behind an insight, to watch, download and share. |
| Context | The Project's Cursor store with canvases, media and working docs. Linked from [key-documents.md](./key-documents.md). |
